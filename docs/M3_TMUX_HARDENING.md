# M3 tmux runtime hardening\n\nThe production `context()` now wires the allowlisted WeeChat, Irssi and BitchX persistent sessions to `TmuxSessionRuntime` instead of the read-only placeholder runtime. Client startup remains a fixed tuple selected by trusted code. The tmux `new-session` invocation uses the documented command position after the target; account input cannot supply executable arguments or tmux options.\n
